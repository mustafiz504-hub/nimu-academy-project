# Nimu Academy & Bakery

A comprehensive digital platform for **Nimu Academy & Bakery**, featuring a professional baking academy system and an online bakery store. The project is designed with a multi-client architecture to provide seamless course registration, interactive baking learning, and custom bakery ordering.

## 🚀 Key Features

* **Baking Academy & Courses**: Online/offline baking class management, scheduling, video streaming with interactive progress tracking, and certificate search.
* **Bakery Store & Ordering**: Online cake ordering system, custom cake booking, and order status updates.
* **Admin Dashboard & Analytics**: Role-based access control (RBAC), sales reporting, enrollment tracking, and automated certificate generation.
* **Secure Payments & Cloud Media**: Sandbox integration with Razorpay for payments and chunked uploads (via Cloudinary) for streaming-ready course videos.

## 🛠️ Tech Stack & Architecture

* **Backend**: Node.js & Express API with a robust database schema.
* **Web Client**: React + Vite for a high-performance admin and user interface.
* **Mobile Client**: React Native + Expo App for mobile-optimized course learning and browsing.
